## 一、总览：数据怎么流动

```
原料/（助教发放的全国数据与专利）
   │  ① build_jjj_master.py：省份过滤→规范化→去重→坐标核查
   ▼
01_必做_感知模块/outputs/master_clean.csv（38,553 家京津冀主表）
   │  ├─→ 02 模块全部脚本（环节词表/基线/统计/图/抽查）
   │  └─→ 司马台总数据_新一代信息技术.xlsx（15 列引擎接口格式）
   │         │  ② 拷入引擎 输入数据/新一代信息技术/（连同政策/龙头/POI/上中游表）
   │         ▼
   │      一键换链引擎（config.json 指向新链，eps=5km/min=75）
   │         │  ③ 一键运行分析.ps1 → 生成_29/31/32 后处理
   │         ▼
   └──────→ 03_必做_集群识别模块/outputs/（引擎产物 + 标准化成员表 + 验证文档）
```

环境：系统 Python 3.11 + pandas/matplotlib/openpyxl（模块脚本）；引擎自带 `内部程序/.venv`（无需配环境）。
编码约定：原料=GBK（脚本内已处理）；所有产出=utf-8-sig（Excel 可直接打开）。

## 四、02_必做_企业分析模块

| 文件 | 作用 | 生成过程 |
|---|---|---|
| `scripts/seg_rules.py` | **公共规则库**（被本模块其他脚本 import）：4 环节口径与别名、关键词基线规则、上下文规则（安全+生产/工程→配套）、城市归并（京津区→直辖市）、资本/年龄分档、主环节与路径解析函数 | 人工编写（NEV 版参数化改造） |
| `scripts/make_segment_vocabulary.py` | 环节词表生成：主表→解析路径首条→环节→中类→节点计数、定义、代表企业（综合能力评分前 3） | 运行后产出 `segment_vocabulary.csv`（38 节点行）与 `.md` |
| `scripts/segment_baseline.py` | 关键词基线：仅看企业名称分类（独立于数据标签）→与数据环节算覆盖率/一致率/交叉表 | 产出 `segment_keyword_report.md`（覆盖 9.7%、一致 74.7%）、`segment_predictions.csv`（38,553 行企业级环节画像）、`segment_disagreement_sample.csv`（不一致抽样 60 条） |
| `scripts/segment_stats.py` | 地区统计：14 市×环节交叉、城市总表、年龄结构、规模结构（仅人民币；注册资本≠营收声明）、典型企业（每市注册资本前 5，注明维度≠营收）、京津冀 vs 全国环节对照 | 产出 `outputs/stats/` 6 张表 |
| `scripts/segment_figures.py` | 三张图：fig1 城市×环节热力、fig2 成立年份直方、fig3 规模结构堆叠 + 3 个 `.caption.md` 图说（画什么/怎么读/说明/局限） | 产出 `outputs/figures/` |

| `outputs/llm_labels.csv` | **大模型初裁标签**：100 家逐家"建议环节+理由"（含 20 家难定），基于名称+路径+模型知识推理，**未联网逐家核查** | Kimi 人工撰写（AI 初裁，非脚本） |

## 七、关键口径速查（答辩可能被问）

- **主环节**：环节列首个值（多标签 2,391 家，6.2%）；节点=完整路径首条
- **城市**：北京/天津的区县级归并为直辖市；河北保持地级市（共 14 个统计单元）
- **规模档**：仅人民币注册资本入档（非人民币 789 家入"未知"未折算）；**注册资本≠营收**
- **年龄**：2026 − 成立年份（快照 2026-08-10）
- **环节标签噪声**："工业互联网平台"(20,062)/"检测评估"(8,641) 两桶口径偏宽——结构画像可用、企业级断言须经抽查（记分牌：基线 68.8% > 数据标签 47.5%）
- **AI 使用分层**：基线=规则；大模型=知识推理初裁（未联网逐家核查）；人工认定=终审（待）；政府口径=外部宏观验证
