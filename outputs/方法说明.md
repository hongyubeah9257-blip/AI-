# 选做⑤ 集群生长模拟与预测 · 方法说明

> 日期：2026-10-21 ｜ 链条：京津冀 · 新一代信息技术（网络安全与工业互联网）
> 课程依据：选做模块⑤——"从企业数量、规模类别、空间扩张等角度，设置不同情景并模拟集群生长变化"
> 建议输出对照：预测模型（选择压力函数）｜情景设定（3 情景规则）｜误差评估（模型对比表+失败案例）｜空间/规模演化结果（投影表+轨迹图）

## 1. 设计思路（三状态空间 + 选择压力）

把每个集群看作同时在三个状态空间中的点，用"集群—年份"面板把三个空间连接起来，再在面板上估计"选择压力函数"——环境对各类集群状态的选择方向与强度，最后用估计结果做情景化演化模拟：

| 状态空间 | 变量（每年每集群） | 来源 |
|---|---|---|
| A 结构空间 | 4 环节占比（上游/中游/下游/配套服务） | 成员口径（必做② 词表） |
| B 规模-年龄空间 | 当年新设、累计存量、近 5 年新设占比、新设率 | 主表成立时间 × 标准化成员表 |
| C 空间-密度空间 | 最小边界面积、密度=存量/面积 | 29 号核心集群表（培育型无面积，标记缺失） |

**选择压力函数**：下一年新设（率）= f（当年可观测状态），在面板上用时间切分估计（≤2021 训练，2022–2025 测试，禁用未来信息）。
**价值定义（措辞红线）**：f 的系数只读作**显示性偏好**——环境数据显示出的选择方向（如"上游占比系数为正"=环境奖励上游集聚的集群），不声称企业主观偏好。

## 2. 面板关键发现（`cluster_year_panel.csv`，23 正式集群 × 1990–2025，828 行）

- **区域新设节奏：2015 年见顶（2,132 家）后持续退潮至 2024–2025（约 1,030 家）**——该链创业潮在"双创"+工业互联网政策窗口（2014–2016）达峰，此后进入存量深耕期。这是后续所有预测的大背景。
- C01（北京）2015=11,542 → 2025=17,869，增速放缓但未停止；C03（石家庄）同期近乎三倍（1,002→2,811），为相对高增长集群。
- 结构空间：23 个正式集群中 12 个下游主导、11 个配套服务主导，**无一上游或中游主导**——与必做②"京津冀偏应用+服务"的环节结构互证。

## 3. 模型对比与失败案例（`selection_pressure_model.md` / `forecast_metrics.csv`）

| 模型 | 构成 | 测试期 MAE（2022–2025，新设数） | 结论 |
|---|---|---|---|
| 朴素基线 | 下一年=当年新设 | **14.9** | **赢家，作模拟骨架** |
| A 率-状态 | 新设率 ~ log存量+环节占比+年轻化+年份 | 68.8 | 失败（纯状态模型在强惯性序列上必败） |
| B 率 AR+状态 | A + 率惯性项 | 73.7 | 失败（率惯性弱，AR 系数仅 0.10） |
| C 对数水平 AR+状态 | log新设 ~ log当年新设+log存量+环节占比+年份 | 26.6 | 最接近但未超朴素；**采用其系数作选择压力方向判读** |

**失败案例（报告素材）**：三格模型的递进失败说明——年度面板上的集群生长是强路径依赖过程（累积因果），状态空间特征有方向性信息但**不足以转化为点预测优势**。这与演化经济学"路径依赖主导集群演化"的判断一致。
**选择压力方向（模型 C 系数）**：上游占比 +2.50（环境奖励上游集聚，最强信号）、log存量 +0.88（累积优势）、log当年新设 +0.48（惯性）、年份 −0.014（区域退潮）、近 5 年占比 −0.002（≈0）。

## 4. 三情景模拟 2026–2028（`scenario_projection.csv` / `fig_growth_scenarios.png`）

规则透明（幅度为分析约定，方向来自模型 C 系数符号）：

| 情景 | 规则 | 含义 |
|---|---|---|
| 基准 | 各集群新设维持 2025 年水平 | 无政策变化的惯性世界 |
| 配套增强 | 上游占比前 1/3（≥6.8%）集群新设 ×1.10/年 | 强化上游配套的政策环境（奖励模型 C 中最强正信号） |
| 容量收紧 | 密度前 1/3（≥2.0 家/km²）集群新设 ×0.80/年 | 空间容量约束（培育型无密度不罚） |

- **波动带**：基准情景按测试期朴素相对残差自助抽样（200 路径）取 10–90% 分位。
- **结果要点（2028 存量，Top 集群）**：C01 基准 18,211 / 配套增强 18,284 / 容量收紧 18,092；C03 3,420 / 3,550 / 3,207。**读法**：3 年窗口内存量（累计量）变化必然微小，**差异主要体现在新设流量**——如 C01 2028 年新设：基准 ≈110 家 vs 配套增强 ≈146 家（+33%）vs 容量收紧 ≈56 家（−49%）。演化方向判读：基准下全区域延续"存量深耕"；配套增强主要利好 C01、C03 等上游占比较高集群；容量收紧对高密度核心（C01/C02）形成压制——北京一极在两种政策方向下都首当其冲。

## 5. 局限（必须随结论一起声明）

1. **退出/迁出不可得**：经营状态 90.7% 缺失，"进入退出预测"实际为"进入与净增长预测"，退出侧为数据边界。
2. **点预测不作断言**：任何模型未跑赢朴素基线，投影只作情景对比与方向判读，不宣称精确预测；**不宣称预测集群存活周期**（课程红线）。
3. 情景幅度（×1.10/×0.80）为分析约定而非估计值；环节占比在模拟中固定（结构缓变假设）。
4. 面板仅含 1990 年后注册企业（32,405 名正式成员中 31,666 家有 1990 后成立年份）；密度仅核心集群可算。
